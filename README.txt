使用方法

1. 将整个项目文件夹上传至 Overleaf，设置 main.tex 为主文件，使用 pdfLaTeX 编译。
2. 不要只复制 main.tex；它依赖同目录的其他 tex 文件和 figures 文件夹。
3. 你的原文、标题、公式、图注、表格及全部11条参考文献均按原源文件直接拆分，没有改写。
4. preamble.tex 以老师的版本为基础，保留老师2.0cm页边距，并追加编译原内容所需的包。分页和外观可能改变。
5. 原有手写参考文献保存在 bibliography.tex；为避免改变条目文字与显示形式，没有强行转成老师示例的 BibTeX 格式。不需要运行 BibTeX。
6. figures 中的分析图提取自已经检查的最终PDF，保留其中的图像内容；校徽取自老师原模板。
7. 原 Downloads 中的文件完全未修改。

验证结果：已通过本机内置 LaTeX 编译器完整编译；封面、摘要、正文、附录、参考文献五个内容块与原源文件逐字一致。
